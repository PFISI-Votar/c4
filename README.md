# Diagramas C4 para la arquitectura de VOTAR

VOTAR es una aplicación de votación descentalizada basada en blockchain, que permite a los votantes emitir sus votos de manera segura y transparente. 

`Para poder visualizar correctamente los diagramas C4, es necesario instalar la extensión "likeC4" en Visual Studio Code. `

 - Link de la extensión: [likeC4](https://marketplace.visualstudio.com/items?itemName=likec4.likec4-vscode)
 - Link al repo: [likeC4 GitHub](https://github.com/likec4/likec4)
